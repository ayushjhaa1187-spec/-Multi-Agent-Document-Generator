## 2024-04-15 - Prevent Unnecessary Re-renders During AI Streaming
**Learning:** In Next.js applications using the Vercel AI SDK's `useChat`, streaming rapid token chunks triggers frequent, unavoidable state updates for the entire `messages` array. As the message list grows, re-rendering all prior static components (like Copy buttons, avatars, or timestamps inside the `messages.map` list) on every token chunk creates a severe main thread bottleneck that can cause UI jank and typed-input lag.
**Action:** When implementing chat interfaces with `useChat`, wrap static or pure list item subcomponents (e.g., `CopyButton`) inside `messages.map` with `React.memo()`. This ensures only the actively streaming message component updates while preventing costly reconciliation of the entire historical message tree.
