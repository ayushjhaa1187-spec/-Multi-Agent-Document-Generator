## 2026-04-17 - Component Memoization\n**Learning:** In React chat interfaces using the AI SDK (`useChat`), pure list item components like `CopyButton` inside `messages.map` must be wrapped with `React.memo()` to prevent unnecessary re-renders during rapid message streaming, reducing frontend performance overhead.\n**Action:** When adding new interactive elements to message lists, evaluate if they are pure components and use `React.memo()` if their props do not frequently change.
