## 2024-03-14 - Optimize AI Chat Streaming and Rendering
**Learning:** In AI chat interfaces using Vercel AI SDK's `streamText`, synchronous database connectivity checks (like `prisma.$queryRaw\`SELECT 1\``) block the initial token stream and significantly worsen Time-To-First-Token (TTFT). Since actual data persistence is safely deferred to the `onFinish` callback, pre-flight DB checks are an unnecessary bottleneck. Additionally, pure components rendered within a mapped list of streaming messages (e.g. action buttons) will unnecessarily re-render on every token update if not memoized.
**Action:** Always wrap static/pure message sub-components with `React.memo` when using `useChat`. Ensure API routes returning streams do not contain synchronous I/O or database checks before returning `streamText(...).toDataStreamResponse()`.
