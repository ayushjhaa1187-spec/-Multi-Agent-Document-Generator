## 2024-07-17 - Add ARIA label to Stop and Project Change buttons
**Learning:** Some buttons might be self explanatory visually through text, but when an action involves something like stopping an async operation or changing a project which essentially resets states, making sure to explicitly include an aria-label helps clarify the button's action for screen readers. Also we should always associate labels with inputs using `htmlFor` and `id` which is missing for the "📋 Project Name" input. Furthermore, the chat input has no `label` or `aria-label` associated with it. We need to add an `aria-label` to the chat input describing its purpose.
**Action:** Always associate labels with inputs using `htmlFor` and `id`, and ensure all inputs and action buttons have clear, descriptive ARIA labels if their purpose isn't fully conveyed by their visible text or lack thereof.
