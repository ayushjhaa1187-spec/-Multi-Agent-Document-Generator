## 2024-06-12 - Prevent Error Stack Trace Leakage via Analytics API
**Vulnerability:** The Analytics Tracker utility (`lib/analytics.ts`) tracks error events, including detailed stack traces (`error.stack`). This data is then retrieved via `getEvents()` and exposed in the `/api/analytics` endpoint. This exposes internal system workings and code structure, a medium severity information leakage vulnerability.
**Learning:** Utilities that automatically aggregate and log full error objects can inadvertently leak sensitive internals if those logs are exposed via API endpoints without sanitization. It was present because the analytics module didn't differentiate between internal diagnostic logging and public data export.
**Prevention:** Sanitize analytic events before they are returned from public access methods (e.g. `getEvents()`). Specifically, use object destructuring to safely exclude fields like `stack` before returning the array. Ensure analytics export logic scrubs stack traces from all serialized output.
