## 2024-XX-XX - Sensitive Data Exposure in Analytics Endpoint
**Vulnerability:** The unauthenticated `/api/analytics` endpoint publicly exposes recent analytics events via `analyticsTracker.getEvents()`. The `AnalyticsTracker.trackError()` method intentionally includes stack traces when tracking errors: `stack: error instanceof Error ? error.stack : undefined`. If an error occurs (e.g., during AI streaming or DB save), the stack trace is saved in memory and then publicly exposed via the unauthenticated `GET /api/analytics` endpoint.
**Learning:** In-memory caching and logging structures must be sanitized before storage or transmission if they are exposed via public metrics APIs, as they can leak sensitive application internals (stack traces, file paths, etc).
**Prevention:** Remove sensitive information (like stack traces) from error events before pushing them to the analytics event array, ensuring that any public endpoint retrieving this array does not leak internal data. Alternatively, ensure public endpoints filter sensitive fields before returning the payload.
